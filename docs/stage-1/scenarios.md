# Каталог сценариев

Автоматизация вызывает существующие обработчики основной формы и меняет виджеты
с активными Qt-соединениями. Диалоги подменяются только для выбора точного пути.
Цикл Qt работает offscreen; это минимальная GUI-проверка, не визуальная приёмка.
Каждый сценарий — отдельный процесс и временный рабочий каталог с кириллицей и
пробелами. Исходники копируются без сортировки: порядок чтения записан в манифесте.

## FULL — одинаковая последовательность для LVM и TWF

| Снимок | Действия |
| --- | --- |
| 01-load | Выбор полного каталога примеров; обработчик open_dir/open_dir_old |
| 02-select | Выбрать только каналы 1, 2 |
| 03-interval | Задать 10–150, вызвать calc |
| 04-mean-norm | LVM: усреднение огибающей 60; обоим: окно 40, coeff_norm 0.2 |
| 05-sum | sum1/sum1_old выбранных каналов |
| 06-quality | recalc_qual_new/old с фактическими порогами формы |
| 07-cement-source | Оставить только канал 1; calc_int_cement |
| 08-correction | Режим сдвига, диапазон коррекции 20–30, corr_sig, fix_corr; выбрать НЦ, попытаться задать 40–45, add_undefine |
| 09-cementogram | cementogramma, PNG, result_cement.txt и options |
| 10-save | save_cement: настоящий DOCX и VAC |
| 11-restore | open_options после загруженных исходников; снимок после восстановления |
| 12-reload | Повторно загрузить исходный каталог в той же сессии |

Все неуказанные настройки — значения исходной формы. Полный фактический набор,
включая состояния кнопок, тексты каналов, окно, коэффициенты, пороги и дату,
сохранён в settings.json каждого снимка. Фиксирована дата 2026-10-19.
Установка 40 до верхней границы 45 в шаге 08 ограничивается Qt: фактически min=0,
max=45; реальный интервал в этой проверке [0,600] по индексам. Это зафиксированное
поведение последовательности действий, не интервал 40–45.

Для LVM каналы 1–8 соответствуют первым восьми чтениям read_order, noise — девятому;
для TWF noise — первому, каналы 1–12 — последующим двенадцати. Список повторён
в read_order при повторной загрузке. Имена не используются для угадывания ролей.

## Изолированные сценарии

`--case single`: один файл в пустую сессию; `after-dir`: каталог, затем один файл;
`unequal`: один полный файл, затем его укороченная копия, выбор 1+2 и попытка суммы.
Укороченные данные создаются только во временном каталоге. Это техническая проверка,
не дополнительный промысловый набор.

`cancel-dir`, `empty-dir`, `cancel-file`, `invalid`, `no-data`, `missing` проверяют
отмену каталога, пустую папку, отмену файла, неверный формат, расчёт без данных
и комплект только с одним файлом. `missing-noise`/`missing-channel` удаляют файл, назначенный шумом/первым каналом фактическим legacy-порядком; имя удалённого файла записано в removed_input манифеста. Исключения здесь — ожидаемое legacy-поведение,
а не исправленная обработка ошибок. Результаты находятся в cases/*.json.

## Проверки, требующие отдельного выполнения

| Сценарий | Причина отсутствия приёмки | Следующее действие |
| --- | --- | --- |
| Windows, нативные диалоги, масштабирование, шрифты | Нет Windows/графического рабочего стола | Повторить FULL вручную на Windows и Linux GUI |
| Визуальная оценка Word и графиков | Offscreen не подтверждает вёрстку Word | Открыть report.docx, сверить подписи, оси, кривые и разрывы страниц |
| PDF, суммы 2/3, коррекция по минимуму/квадратичная, все графики | Не включены в автоматизированный эталон FULL | Отдельные сценарии до переноса соответствующих функций |
| Архивные .vac другого происхождения | Не предоставлены | Проверять только после получения доверенных примеров |


Эти ограничения запрещают считать эталоном все возможности приложения.
