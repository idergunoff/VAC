## Повторение

Активировать окружение по README репозитория. Из корня:

```bash
python tests/check_regression_compare.py
python tools/regression.py compare --device new --baseline tests/baselines/stage-1/new --output work/check-new
python tools/regression.py compare --device old --baseline tests/baselines/stage-1/old --output work/check-old
```

Выходной каталог должен быть новым. Запуск пишет рабочие экспорты только во
временный каталог, а проверочные снимки — в явно указанный --output.
Для нового кандидата: `record` вместо `compare`, без --baseline. Кандидат не
заменяет утверждённый эталон автоматически. Перед заменой изучить различия.

## Формат эталонов и сравнение

`tests/baselines/stage-1/{new,old}` содержит manifest.json с SHA-256 всех входов,
порядком чтения, версиями Python и всех установленных пакетов, хешами кода и
ресурсов. Каждый снимок содержит все непустые DataFrame приложения, структуру
столбцов/индексов, численные NPZ без pickle, значения формы, ручные интервалы,
непрерывные интервалы классов, данные кривых pyqtgraph/Matplotlib и подписи осей.
Сырые значения после legacy-загрузки и обработанные столбцы сохранены вместе;
оригинальные байты входов остаются в `пример` и проверяются по SHA-256.

Формы, dtype, индексы, порядок столбцов/каналов, глубины, метки классов и границы
интервалов сравниваются точно. Маски NaN, +Inf и -Inf должны совпадать отдельно.
Для остальных чисел задан rtol=atol=1e-12 — узкий запас для округления float64
в неизменном стеке, значительно ниже точности исходных измерений. На двух
локальных прогонах различий не обнаружено. Этот допуск не является оценкой
физической погрешности и не утверждён для других версий SciPy/платформ.
Числа в object-столбцах статистики сериализуются строками и сравниваются точно.
Зависимости/Python должны совпасть; хеши кода записаны для происхождения, но
изменение кода само по себе не запрещает регрессионное сравнение при рефакторинге.

DOCX сравнивается по тексту параграфов, включая вложенные таблицы, и хешам
встроенных изображений. ZIP-метаданные и время создания не сравниваются.
PNG сравниваются точно как встроенные изображения в рамках одного стека;
расхождение требует изучения, автоматического расширения допусков нет.
Сохраняются настоящие report.docx/settings.vac. VAC проверяется только через
legacy open_options на собственном доверенном файле; сторонний pickle не читается.

Численное сравнение и минимальный GUI-прогон автоматизированы; визуальная
приёмка — отдельная ручная работа. Эталон подтверждает повторяемость legacy,
а не физическую корректность метода. Полная приёмка этапа 0 и перечисленные
в scenarios.md ветки остаются открытыми; этап 1 не объявлен полностью закрытым.
