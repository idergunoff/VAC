# Результаты и известные расхождения

## Подтверждено

FULL new и FULL old: по 12 успешных шагов, без исключений Qt. Второй независимый
запуск совпал с первым по всем снимкам. Получены настоящие DOCX и VAC для обоих
типов оборудования. Проверка CLI compare дополнительно пройдена на single LVM.
Мутационные проверки comparator отвергают изменение классов, глубин, формы,
появление/исчезновение NaN и Inf. Проверки совместимости не используют mini.

Для isolated cases точные исключения и состояния Qt сохранены в cases.json и
cases/*.json. Запуск `python tools/check_legacy_cases.py --output work/cases-check`
повторяет 22 исхода, включая ожидание legacy-ошибок и ограничение процесса.
Его PASS означает совпадение с зафиксированным исходом, а не исправность входа.

## Не проверено

Windows, реальный GUI Linux, визуальная вёрстка DOCX и оставшиеся ветки из
scenarios.md. Увеличение допусков или исправление перечисленных проблем в эту
работу не включены. Этап 0 остаётся с открытой платформенной приёмкой.

Следующий шаг: ручная приёмка отчётов и интерфейса, затем дополнительные
сценарии PDF/вариантов коррекции перед переносом соответствующих функций.

Удаление отдельно шума и отдельно канала проверено для обоих типов оборудования;
оба неполных комплекта завершаются IndexError при обновлении чекбоксов, после
частичного изменения состояния. Точные удалённые файлы указаны в cases/*.json.
