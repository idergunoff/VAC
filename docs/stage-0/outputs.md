# Выходные файлы и побочные эффекты

Все относительные имена ниже разрешаются от текущего рабочего каталога. При повторном действии файл с тем же именем перезаписывается, отдельного подтверждения нет. Названия получены статическим просмотром исходника; это не утверждение об успешном выполнении всех экспортов.

| Файлы | Кто пишет | Когда |
| --- | --- | --- |
| `result.txt`, `all_stat.txt`, `all_signals.txt` | `calc_to_int` | Пересчёт нового оборудования, включая загрузку каталога |
| `result_old.txt`, `all_stat_old.txt`, `all_signals_old.txt` | `calc_to_int_old` | Пересчёт старого оборудования |
| `result.txt`, `result_old.txt` | `change_mean_win`, `change_mean_win_old` | Смена окна усреднения/связанных коэффициентов |
| `all_signals.txt`, `all_stat.txt` | `sum_signals` | Расчёт суммы нового оборудования |
| `result_old.txt`, `all_stat_old.txt` | `sum_signals_old` | Расчёт суммы старого оборудования |
| `all_signals.txt` | `calc_pdf` | Расчёт PDF нового оборудования |
| `temp.png`, `temp1.png`, `temp2.png` | `cementogramma` | Первая страница; дополнительные при глубине >400 и >800; старые дополнительные PNG автоматически не удаляются |
| `result_cement.txt` | `cementogramma` | Таблица итоговой цементограммы |
| `graphics_new1.png`, `graphics_new2.png` | `draw_graphics` | Общие графики нового оборудования |
| `graphics_old1.png`, `graphics_old2.png` | `draw_graphics_old` | Общие графики старого оборудования |
| `цементограмма_по_скв_<номер>.docx` | `save_cement` | Сохранение Word-отчёта |
| `options_<номер>.vac` | `save_cement` | Pickle-словарь options; запись выполняется и после перехваченного PermissionError при сохранении DOCX |

`save_cement` читает `template.docx` и изображения `temp*.png`; шаблон не перезаписывается. CSV/TXT сохраняются с табуляцией и индексом pandas. `cementogramma` создаёт глобальный `options`; он содержит диапазон обработки, пределы/пороги цементограммы, имя сигнала и список `corr_sig`, но не оригиналы измерений и не полную историю обработки. `.vac` предполагает уже загруженные совместимые измерения. Загружать следует только доверенные `.vac`: используется `pickle.load`.

Другие эффекты: запуск при импорте модуля и `sys.exit`, изменение виджетов и соединения Qt-сигналов, открытие окон Matplotlib, очистка графика/таблиц при действиях, изменение глобальных таблиц и интервалов. Изменение значения виджета может немедленно вызвать новый расчёт; порядок действий имеет значение. Вспомогательные кеши Qt/Matplotlib зависят от окружения.
