# Журнал известных проблем

Дата: 20 октября 2026. Расчёты, форма и пороги в ходе этапа 0 не изменены.

| ID | Статус и подтверждение | Влияние | Следующий шаг |
| --- | --- | --- | --- |
| ENV-01 | Воспроизведено: `calc_to_int:336`, `calc_to_int_old:420` передают numpy.float64 в QSpinBox.setValue | Оба smoke загрузки завершаются TypeError до полного расчёта | Отдельное исправление совместимости: определить правило округления окна, документировать влияние на обработку, повторить оба сценария; не выдавать такой результат за прежний численный эталон |
| STATE-01 | Статически: open_dir_old присваивает k_oldtonew без global; open_sig_old объявляет global | Возможное различие масштабирования при добавлении TWF после загрузки каталога | Воспроизвести сценарий каталог → отдельный файл на этапе 1 |
| ORDER-01 | Статически: os.walk без сортировки каталогов для LVM, os.listdir для TWF; роль шума зависит от позиции | Назначение каналов может различаться между платформами/каталогами | Записать фактический порядок до любых изменений; не сортировать автоматически |
| API-01 | В логах загрузок: pandas FutureWarning/ChainedAssignmentError о цепочечном присваивании | Обновление pandas/Copy-on-Write может изменить поведение | Сохранить версии; перенос присваиваний отдельными проверяемыми изменениями |
| IO-01 | Статически: шаблон и экспорты используют CWD | Запуск из другого каталога не находит шаблон; повторный запуск перезаписывает результаты | Пока запускать из корня; исправление путей запланировано в этапе 2 |
| IO-02 | Статически: отмена диалога и неполные комплекты не проверяются до индексации/чтения | Возможны исключения и частично очищенное состояние | Зафиксировать каждый негативный сценарий на этапе 1 |
| IO-03 | Статически: .vac содержит часть состояния и читается через pickle | Требует исходников/предварительной загрузки; не является полным архивом | Проверить совместимость на доверенном примере, документировать ограничения |
| REPORT-01 | Статически: сохранение использует фиксированные индексы таблиц/runs и temp*.png; PermissionError DOCX не останавливает запись VAC | Изменение шаблона/порядка действий может нарушить отчёт; частичный экспорт | Проверить полный сценарий и открыть DOCX вручную после снятия ENV-01 |
| GUI-01 | В offscreen логах предупреждения Fontconfig, XDG_RUNTIME_DIR и propagateSizeHints | Внешний вид не подтверждён | Проверить в графической сессии с установленными шрифтами |
| VERIFY-01 | Windows и реальный Linux GUI недоступны | Платформенная приёмка не завершена | Пройти матрицу scenarios.md на обеих платформах |

Этот журнал различает воспроизведённые ошибки и находки статического просмотра. Непроверенные сценарии не считаются исправными. Изменения методики и предположения о физических единицах не выполнялись.
