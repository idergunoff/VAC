# Этап 0 — инвентаризация и воспроизводимый запуск

20 октября 2026 года. **Инвентаризация и доступные проверки выполнены; полная приёмка этапа 0 остаётся открытой.** Основная форма запускается headless, но автоматический пересчёт обоих комплектов останавливается на ENV-01; Windows и реальный GUI недоступны. Это не подтверждение полной работоспособности.

Обычный git fetch не работает из-за недоступности прокси, поэтому локальные ссылки Git не обновлены; актуализация файлов не является merge/rebase. Материалы подготовлены для отдельного PR в master.

План прочитан из master: blob `82c5e6ec122e97e7646622328bffd82ce21e365a`. Этап 0 не меняет VAC_python.py, standard.py, формы, шаблон, mini и исходные измерения.

## Окружение и проверка установки

Debian GNU/Linux 13.6 (trixie), x86_64, glibc 2.41; ядро 6.18.55. CPython 3.12.14, 64 бит. Новый venv `work/venv` создан из доступного Python 3.12; установлены все 8 прямых зависимостей из requirements.txt и их зависимости, всего 23 пакета. Установка выполнена offline из кеша uv, не путём подключения site-packages прежнего окружения. `uv pip check` подтвердил совместимость всех пакетов. Сетевое скачивание с чистого компьютера не проверено: прокси недоступен.

Команды, выполненные из окружения задачи:

```sh
UV_CACHE_DIR=/workspace/.cache/uv uv venv --python /workspace/.venvs/vac/bin/python /workspace/VAC/work/venv
UV_CACHE_DIR=/workspace/.cache/uv uv pip install --offline --python /workspace/VAC/work/venv/bin/python -r /workspace/VAC/requirements.txt
UV_CACHE_DIR=/workspace/.cache/uv uv pip check --python /workspace/VAC/work/venv/bin/python
```

Пользовательская установка через pip описана в [README](../../README.md); uv — использованный здесь установщик, не зависимость приложения. Полный снимок 23 версий: [requirements-linux-py312.lock.txt](requirements-linux-py312.lock.txt). Windows-совместимость этого снимка не заявляется.

## Остаток и следующий шаг

Отдельно решить ENV-01 с явно выбранным правилом целочисленного окна и оценкой влияния, повторить загрузки; затем пройти ручную матрицу на Windows и Linux. До этого этап 0 не отмечать полностью завершённым. Этап 1 должен сохранить фактический порядок каналов, значения настроек и численные результаты до разделения кода. Массовое обновление зависимостей и изменение формул не выполнялись.
