# Метод интерпретации и оценка изменений

## Что сделано

Добавлен независимый модуль `vac.evaluation` на стандартной библиотеке Python.
Модуль оценивает уже полученные метки на общей равномерной оси индексов, не запускает
расчёт и не требует Qt или архива. Запуск:

```sh
python -m vac.evaluation согласованная-выборка.json work/evaluation-result.json
```

Выходной файл должен быть новым. Результат содержит параметры, версии алгоритма,
кода, эталонов и разметки, гипотезу, SHA-256 входного JSON и самого оценщика.
Для повторения сохраняйте JSON, исходные измерения с указанными хешами, код,
зависимости и эталоны. Декларируемые хеши измерений требуют отдельной проверки
при подготовке выборки: оценщик не открывает исходные LVM/TWF.

Формат входа показан в [синтетическом примере](evaluation-example.json).
Он нужен только для проверки механики и не содержит промысловых заключений.
`study_id` уникален, `well_id` — устойчивый идентификатор физической скважины,
`input_sha256` идентифицирует комплект входных данных. Все повторные исследования,
каналы и соседние отсчёты скважины должны оставаться в одной части выборки.
Инструмент отклоняет пересечение скважин и одинаковых комплектов между
`train`, `validation`, `evaluation`. Проверяется вся декларация разделения,
оценивается только `evaluation`. Правильность идентификаторов обеспечивает куратор.
При нескольких каналах подготовьте отдельные оценочные запуски с одинаковым
разделением; повторять `study_id` в одном документе нельзя.

`truth` и `prediction` — одинаковой непустой длины, целые метки:
0 — качественный, 1 — частичный, 2 — отсутствие, 3 — неопределённость.
Неопределённость эксперта — отдельный класс; пропуски разметки не заменяются на 3.
До оценки выделите полностью размеченный непрерывный участок; не склеивайте
разобщённые интервалы. Сохраните его начальный индекс, шаг и единицы оси в
`parameters`, а также точный канал и способ получения предсказаний. Метки за
пределами расчётного интервала, заполненные legacy нулями, не являются прогнозом.
Убывающие/неравномерные физические оси сначала требуют согласованного адаптера;
границы здесь измеряются в отсчётах, а не в метрах.

## Метрики: предложения для согласования

- Матрица ошибок: строки — эксперт, столбцы — прогноз, порядок классов 0–3.
- По каждому классу: support, precision, recall, F1, IoU; нулевой знаменатель
  обозначается JSON `null`. Accuracy включает неопределённость как класс.
- Доля неопределённых прогнозов и доля экспертной неопределённости отдельно.
- Для каждого непрерывного полуоткрытого сегмента `[start,end)` — лучший IoU
  с сегментом того же класса; также обратное направление. Это диагностические
  списки, не взаимно однозначное сопоставление и не критерий приёмки.
- Для каждой внутренней границы — расстояние до ближайшей границы с тем же
  направленным переходом классов, в обоих направлениях. Среднее считается
  только по найденным парам; отдельно выводятся число несопоставленных границ
  и количества границ. Если пар нет, расстояние `null`. Края участка исключены.
  Близкие повторные переходы могут использовать одного соседа: это не matching.

Результаты сохраняются по исследованиям; глобальное усреднение по отсчётам
не скрывает различия длин скважин. Макроагрегацию, веса ошибок, допустимое смещение
границ и допустимую неопределённость должен согласовать предметный специалист
**до** просмотра результатов кандидата на отложенной выборке.

## Физические предпосылки и открытые вопросы

| Наблюдаемый код | Реальное поведение | Что требуется подтвердить |
| --- | --- | --- |
| `vac.io.lvm`, `preprocessing.envelope` | Абсолютный сигнал, максимумы, интерполяция огибающей и сглаживание | Единицы осей и применимость к оборудованию |
| `preprocessing.twf_depth`, `interpolate_twf` | Масштаб 0.515, шаг 0.05839; TWF заголовок 130 байт | Происхождение коэффициентов и физическая ось |
| `vac.calculation.calculate_new/old` | Нормирование на сглаженный сигнал с добавкой, аппроксимация, разностный показатель | Физический смысл параметров и диапазон применимости |
| `interpretation.individual_thresholds` | Трети диапазона min/max на выбранном интервале; средние пороги по каналам | Обоснование порогов и чувствительность к выбросам |
| `calculation.classify` | 0/1/2, ручная 3; absolute и интервальный режимы; подавление коротких участков `<17` отсчётов | Комментарий «менее 1 метра» не доказывает единицы; концевой участок обрабатывается иначе |
| `interpretation.damping_class` | Отдельные пороги 0.3233 и 0.6806 | Обоснование и связь с основным классификатором |
| `vac.reference` | Сохранены исходные кривые `good_*`, `bad_*`, `depth_*` | Автор, измерения, калибровка, оборудование и условия скважины неизвестны |

Это описание реализации, не физическая валидация метода. Ошибки и частичные
классификации legacy должны сопровождать экспорт прогнозов; их нельзя скрывать
заполнением метками. Автоматические прогнозы оцениваются отдельно от ручных правок;
правки того же эксперта не могут служить независимым подтверждением результата.

## Следующие предметные действия

1. Куратор предоставляет исследования разных скважин, оборудование и условия,
   разрешение использования, единицы осей и происхождение эталонов.
2. Эксперты независимо размечают интервалы четырёх классов; сохраняются автор,
   версия, спорные границы, разногласия и отдельно согласованное заключение.
3. До эксперимента фиксируются разделение по скважинам, размеры частей,
   метрики/порог приёмки, одна гипотеза и параметры базового запуска.
4. На замороженной оценочной выборке запускаются baseline и один кандидат;
   сравниваются одинаковые исследования, спорные интервалы и устойчивость.
5. Предметный специалист принимает ограничения и результат. Только после этого
   новая версия подключается к рабочему процессу как отдельный алгоритм/запуск.

Существующий архив уже хранит версию алгоритма и отдельные запуски. Новая методика должна создавать отдельный запуск; старые отчёты сохраняют
связь с прежним результатом. Экспертная оценка качества пока не выполнена.
