# Жизненный цикл состояния

Состоянием владеет экземпляр `Controller`, связанный с одним окном. `ApplicationState`
передаётся в конструктор; глобального экземпляра нет. Два окна не разделяют таблицы.
Модель импортирует pandas, но не Qt, отчёты или хранение.

| Событие | Измерения / статистика | Результат | Интерпретация и ручные правки |
| --- | --- | --- | --- |
| Создание окна | Два независимых пустых набора; legacy-индексы 1–11 и 1–15 | `None` | `table=None`; пустые интервалы, реквизиты и история |
| Отмена выбора каталога/одиночного файла | Не изменяются | Не изменяется | Не изменяется |
| Подтверждение нового каталога | Только выбранное оборудование: новая таблица и статистика; номер ревизии +1; коэффициент старого оборудования снова 1 | `None`, затем новый результат после успешного расчёта | Очищаются, включая настройки `.vac`; выбранные каналы сбрасываются с блокировкой Qt-сигналов |
| Ошибка чтения после подтверждения каталога | Старый набор уже удалён; возможен неполный новый набор | Не помечается успешно рассчитанным | Прежняя интерпретация отсутствует; атомарный импорт относится к этапу 4/8 |
| Добавление одиночного измерения | Совместимое дополнение таблицы; при заполненном комплекте — новый набор | Устаревает; новый расчёт создаёт снимок параметров | Очищаются до изменения данных |
| Изменение параметров обработки | Исходные столбцы сохраняются | `stale=True`; если legacy-слот выполняет полный расчёт — новый результат | Очищаются; параметры оформления цементограммы не относятся к этой группе |
| Пересчёт усреднения, суммы, PDF | Меняются производные столбцы | Предыдущий снимок помечается устаревшим до пересчёта | Прежние ручные правки сбрасываются |
| Выбор сигнала/PDF для цементограммы | Не изменяются | Не изменяется | Новая привязка `(оборудование, ревизия набора, обозначение сигнала)`; интервалы и история сбрасываются |
| Ручная корректировка | Изменяется только отдельная таблица цементограммы | Не перезаписывает исходники | История операции с привязкой к сигналу, координатами и переключателями режима |
| Формирование цементограммы | Автоматическая классификация прочих каналов не получает чужие ручные интервалы | Сохраняется | Интервалы передаются в `classify` явно только для текущей цементограммы |
| Экспорт Word / VAC | Исходники не меняются | Сохраняется | Снимок реквизитов; прежний формат `.vac` не расширяется |

`None` означает отсутствие результата. Пустая DataFrame — существующий пустой
результат; эти случаи различаются. Операции над цементограммой без выбранного
сигнала завершаются без записи файлов.

## Владение таблицами

- `MeasurementSet.signals` — рабочая legacy-таблица с прежними именами столбцов,
  индексами и вычисляемыми столбцами. Расчёт меняет её на месте.
- `capture_original()` сохраняет глубокую копию `depth`, `noise` и целочисленных
  столбцов каналов до вычислительного прохода. Это вход расчёта после legacy-чтения,
  интерполяции/масштабирования, а не копия байтов LVM/TWF.
- Свойство `original` возвращает копию: внешняя модификация не меняет сохранённый вход.
- Выбранная цементограмма имеет отдельную DataFrame и отдельные столбцы коррекции.
- Статистика, списки каналов, интервалы, история и реквизиты создаются через
  `default_factory`; изменяемых значений, общих для экземпляров, нет.

## Граница параметров

Контроллер получает значения виджетов и создаёт неизменяемый
`ProcessingParameters`: границы, нормирование, сдвиг функции, масштаб производной,
окно усреднения. Рекомендуемое окно и его ограничение Qt сохраняются в контроллере,
после чего готовое значение попадает в снимок. `calculate_new/old` получают набор,
снимок и необязательный callback прогресса; без callback Qt не нужен.

`classify` получает сигнал, пороги, абсолютный режим и `QualityIntervals` явно.
Исключение `ClassificationError` содержит частично рассчитанную классификацию:
контроллер сохраняет прежнее поведение при legacy-ошибке и показывает прежнее сообщение.

Остальные legacy-методы пока находятся в контроллере: дальнейшее отделение чтения,
суммирования, PDF, отображения и отчётности запланировано на этапах 4–5.
`ProcessingResult` описывает актуальность рабочей таблицы и снимок параметров;
это ещё не неизменяемая сохраняемая версия результата для будущей БД.
