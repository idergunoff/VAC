# Документация VAC

[Поэтапный план модернизации](modernization-plan.md) — основной рабочий документ: исходное состояние, границы изменений, этапы, проверки и вопросы по предметной области.

Работа начинается с этапа 0. Реализация приложения в рамках подготовки этого плана не изменялась. Статусы обновляются по фактически выполненным работам; наличие плана не означает завершения аудита или проверки расчётов.
