# Порядок начала работы

Перед работой по любой задаче сверять локальную версию с актуальной версией
репозитория на GitHub. Сначала проверить рабочую копию, remote и текущий HEAD,
затем получить актуальные ссылки GitHub и сравнить коммиты целевой ветки.
Не делать вывод о незавершённых этапах по устаревшей локальной копии.

Если локальная копия отстаёт, получить актуальную базу с сохранением локальных
изменений. При недоступности Git использовать доступный GitHub-коннектор;
при невозможности сверки явно сообщить об этом. Локальная ссылка origin/master
без обновления не подтверждает актуальность GitHub.

В начале реализации указывать проверенный исходный коммит.
Текущая модульная версия принята за базу дальнейшего развития.
Проверки текущего поведения описаны в README.md и tests/fixtures/README.md;
исторические отчёты переписывания доступны в истории Git.
